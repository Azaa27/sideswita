## Catatan penggunaan

- Video ditampilkan sebagai referensi pendukung, bukan klaim bahwa setiap kanal/video diproduksi oleh BUMDes Jalatrang.
- Sumber dapat diganti oleh admin dari **Ruang Admin → Produk → Edit**. Tempel URL YouTube biasa, URL pendek, URL embed, atau ID video 11 karakter.
- Sebelum sidang/publikasi, pemilik sistem sebaiknya meninjau ulang relevansi video, status publik, dan izin dari masing-masing sumber.
