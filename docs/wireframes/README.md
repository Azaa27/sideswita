# Wireframe Jalatrang Wisata

Dokumentasi rancangan awal antarmuka (low-fidelity) untuk Jalatrang Wisata. Seluruh wireframe memakai skala hitam-putih agar tampak sebagai tahap perancangan sebelum aplikasi dikembangkan, bukan tangkapan layar aplikasi jadi.

## PNG hasil generasi

Versi PNG yang siap dipakai pada laporan tersedia di folder `png/`.

| Kelompok | Lembar PNG | Halaman individual |
|---|---|---|
| Jelajah & pemesanan | `png/sheets/01-alur-pelanggan.png` | `png/pages/01-beranda.png` s.d. `png/pages/04-checkout.png` |
| Akun pelanggan | `png/sheets/02-akun-pelanggan.png` | `png/pages/05-masuk-daftar.png` s.d. `png/pages/08-tinjau-pesanan.png` |
| Operasional admin | `png/sheets/03-operasional-admin.png` | `png/pages/09-admin-dashboard.png` s.d. `png/pages/12-admin-tinjau-pesanan.png` |
| Detail & analitik | `png/sheets/04-detail-dan-analitik.png` | `png/pages/13-detail-wisata.png` s.d. `png/pages/16-konfirmasi-pesanan.png` |

Setiap lembar menampilkan empat rancangan dalam satu alur. Folder `pages/` berisi potongan PNG per halaman agar mudah disisipkan satu per satu ke Bab IV atau Bab V.

## SVG pendukung

Versi SVG konseptual terdahulu tetap dipertahankan sebagai aset yang mudah disunting. Mulai dari `00-daftar-wireframe.svg` untuk melihat indeksnya.
